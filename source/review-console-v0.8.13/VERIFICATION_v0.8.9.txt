NOTE ON AN EARLIER TEST RUN
---------------------------
An intermediate test appeared to show startTime and endTime being deleted. That run was invalid:
the harness had mutated validity across several commits and re-renders until the editor was blank,
which is not a state the interface can reach. clear-comment-selection sets selectedCommentId to
null before renderDetail (app.js:4527-4534), so a blank editor cannot commit over a selected
record. The clean isolated re-run passed. Recorded here so the observation is not lost:
the all-empty bail in commitSelectedCommentEditorChanges (app.js:5043) is weakened by billingType
defaulting to "regular", but it is unreachable for the reason above and was NOT changed.
